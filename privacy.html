Page Views and Link Activity

When you view a page or click a résumé download, email, LinkedIn, or GitHub link, this website sends the action name, current page path, application reference code (if present), and referring page address (if provided by your browser) to a Cloudflare Worker. The Worker logs the activity in my Google Sheets activity log and sends me a Telegram notification. These records include the date and time and, when the reference code matches an application, the associated company and position. Click records do not confirm completed downloads, sent emails, or activity on LinkedIn or GitHub.

Application links may include a ref code. This website stores that code in your browser tab's session storage so subsequent page views and tracked clicks retain the same reference as you browse. Session storage normally clears when the tab closes. This tracking code does not use cookies. A reference identifies the application link used to reach the site; it does not verify who opened it.

The notification payload does not include your email address or IP address. Cloudflare receives your IP address as part of handling the network request. Google processes the activity log, and Telegram processes the notification message to deliver it to me. See Google's Privacy Policy and Telegram's Privacy Policy.
